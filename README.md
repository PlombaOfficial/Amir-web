# Amir Web — обновлённый дизайн, версия 2

Светлое оформление с зелёными акцентами по предоставленному референсу. Главный экран с ноутбуком и телефоном, отдельный логотип, адаптация к мобильным экранам, мягкие анимации. Сохранены контакты, проекты, цены 30 000 / 60 000 / 100 000 ₸, русский, казахский и английский языки, тёмная тема и режим уменьшенного движения.

Во второй версии добавлены фотографии, вкладки направлений бизнеса, настоящие снимки проектов с увеличением, подбор формата сайта с ценой и подготовкой сообщения в WhatsApp. В тёмной теме используется отдельная тёмная фотография без светлой засветки. Появились мягкий наклон изображений при движении мыши, эффекты кнопок, смены вкладок, индикатор прокрутки и кнопка возврата наверх. На сенсорных устройствах наклон отключён, настройка уменьшенного движения останавливает декоративные анимации.

Форма работает локально, без сервера и стороннего сервиса форм. Она формирует ссылку WhatsApp с черновиком; посетитель сам нажимает отправку в WhatsApp. Стартовые цены взяты из тарифов сайта. Имя и описание задачи не сохраняются в браузере. Превью проектов — снимки экранов; отдельная кнопка открывает исходный сайт. Teacher Temp обозначен как демонстрационный проект.

## Как открыть

Откройте `index.html` в браузере. Для проверки офлайн-режима и установленного приложения нужен HTTP-сервер или хостинг с HTTPS.

## Как разместить

Загрузите содержимое папки `Amir-web-main` в корневую папку вашего хостинга, сохраняя структуру `assets/`. Сборка, Node.js и установка пакетов не нужны. Сохраните резервную копию прежней версии перед заменой.

Домен, контакты и Google Analytics оставлены из исходного сайта. Аналитика запускается только на `amir-web.kz` и `www.amir-web.kz`; локальные просмотры не учитываются. Публикация на домен не выполнялась.

Если сайт открывали до обновления, обновите страницу после загрузки файлов. Service worker обновлён и удаляет только старые кеши Amir Web. Светлая тема включена по умолчанию; сохранённый ранее выбор пользователя имеет приоритет.

## Где редактировать

- Структура страницы: `index.html`.
- Оформление: `assets/css/styles.css`, блок «White & emerald visual system».
- Новые блоки, фотографии и эффекты: `assets/css/experience.css`.
- Тексты всех языков: `assets/js/i18n.js`.
- Меню, FAQ, настройки: `assets/js/main.js`.
- Вкладки, подбор сайта, превью проектов: `assets/js/experience.js`.
- Отдельный логотип с прозрачностью: `assets/img/logo-mark.png`.
- Изображение главного экрана: `assets/img/hero-devices.webp`.
- Тёмное изображение: `assets/img/hero-devices-dark.webp`.
- Локальные фотографии и снимки проектов: `assets/img/`; источники — в `PHOTO-CREDITS.md`.
- Иконки приложения и обложка ссылки: `assets/img/`, `favicon.svg`, `favicon.ico`.

При изменении русского текста обновляйте и HTML (для просмотра без JavaScript), и словарь `ru` в `i18n.js`. При последующих изменениях ресурсов увеличивайте версию кеша в `sw.js` и версию ссылок на CSS/JS.

## Проверка

Проверены загрузка изображений, внутренние переходы, сохранение темы и языка, русская/казахская/английская версии, мобильное меню, вкладки услуг с управлением стрелками, переключение цены, подготовка заявки, превью обоих проектов и возврат фокуса при закрытии. Все 290 использований ключей перевода в HTML обеспечены словарями на трёх языках. Исходные ссылки связи и портфолио, а также цены сохранены. Сообщения в WhatsApp не отправлялись.

## Изображения

Для выделения логотипа и подготовки визуала использован встроенный ImageGen с предоставленным владельцем изображением. Файлы включены в архив; дополнительных ключей API не требуется. Запросы сохранены в `ASSET-PROMPTS.md`.
